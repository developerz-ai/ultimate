# Error codes: repository scripts

Part of [Error codes](Error-Codes): the codes this repository's own gate scripts raise. They never ship to an app, so `x errors explain` does not know them; the row is the whole answer.

| Code | Means | Typical cause | Fix |
|---|---|---|---|

| `X_ACTIONS_CACHE_OVER_BUDGET` | the Actions cache stays over budget after pruning | entries outside the superseded key families grew past 8 GB, so the 10 GB cap evicts caches before CI restores them | `bun run scripts/actions-cache-prune.ts --json` |
| `X_ADAPTER_PORT_INCOMPLETE` | an adapter port is missing part of its contract, or a backend is swapped outside one | an ADAPTER_PORTS row (packages/core/src/registrar.ts) lacks its RuntimeOverrides field, its boot binding, its ./adapter export or installer, its @ultimat3/testing/conformance suite, or its wiki/Adapters.md section; or a package barrel exports a set*/configure*/install* installer; or a ./adapter subpath exports a port-shaped interface no row lists. A pin in scripts/lib/adapter-port-pins.ts that excuses nothing is the same finding | `bun run scripts/adapter-ports.ts --json, then make the edit each finding names in its own fix; for wiki/Adapters.md: bun run scripts/adapter-ports.ts --write` |
| `X_ADMIN_FLATTENER_VIOLATION` | a production `@ultimat3/admin` file read `$meta` or called `$describe()` directly | a new admin module reached past `entity-columns.ts` for column facts | take `AdminColumnFacts` from `entity-columns.ts` instead |
