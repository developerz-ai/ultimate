# 19 — Agent experience: fixes that are true, one test path, tooling that tells you what to run

> Part of [`overview.md`](overview.md). Depends on: none for 19a; [`13`](13-cli-exercise-verify.md), [`14`](14-cli-commands-upgrade.md) for 19b. Tier: 5 (`cli`, `mcp` dev server), `.claude/`, docs. Two sweeps: **19a** (fix-truth defects) runs right after sweep 0; **19b** (tooling and discovery) runs last.

Measured 2026-11-11 by scaffolding an app (in-repo CLI and the published 31.4.2), building a feature with seven generators and planting 19 mistakes. What works: both scaffolds reach a green 21-step gate first time; generator output passes the gate; `x dev` to first 200 in 4.0 s; page reload 0.12 s, island 0.5 s; cold gate 40.6 s, warm 26.5 s. Where an agent loses time: a printed fix that makes things worse, an error that blames the wrong file, and an MCP server that disagrees with the shell.

4. 19b: Y1 and Y5 are verified by doing: make an edit, see the hook act. Y2 is tested with a read-only agent run that leaves no ref behind.
5. Re-run the same scaffold session at the end; record the timing table and the error-grade table next to the 2026-11-11 one in the PR. Target: no F grade, no fix that worsens the tree.
