# DX / CI ledger — plan 101

Every developer-experience or CI gap the agents working on this plan have reported, **ranked by
agent time saved**. First come gaps that make an agent guess: a doc that lies, two ways to do one
thing, a silent change of meaning, no code, no runnable `fix:`. After them come gaps that only cost
a human some convenience. Each row names a **mechanical** fix (a guard, a code, a fix line or a
generator), and the path that owns it. `As of 2026-09-22`.

**Status values:** `open` means nothing enforces it yet. `closed` names the commit or the check
that now enforces it.
