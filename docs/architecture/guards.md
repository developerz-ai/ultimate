# Guards

GENERATED by `bun run scripts/guards-doc.ts --write` from each script’s own header — never
hand-edited; `--check` refuses drift (`X_GUARDS_DOC_DRIFT`). A guard is a runnable
`scripts/*.ts` that emits at least one code; inclusion here does not prove gate membership.
Most guards enforce through sibling `scripts/*.test.ts` repository assertions run by the
`unit` step: discovery is in `packages/cli/src/test-select.ts`, suite ownership and execution
in `packages/cli/src/verify-tests.ts`. Separately, `HOST_CHECKS` in `scripts/verify.ts` groups
host checks into four families: `boundaries`, `errors`, `manifest` and `roadmap`.
The codes are in
[`wiki/Error-Codes.md`](../../wiki/Error-Codes.md).
