## 31.53.0 - 2026-11-28

### Highlights

- **Motion, ours:** `@ultimat3/ui/motion` is one WAAPI engine on the token scale — springs as CSS `linear()`, `Presence`, `layout()` (FLIP), `stagger`, `inView`, `frameLoop` — with a page-wide `MotionToggle` pause and no runtime dependency.
- **Effects that cost nothing until used:** the new `@ultimat3/effects` package ships 13 backgrounds, surfaces and text effects plus `EffectCanvas`. Each is rendered on the server first, safe under reduced motion, makes no network requests, and has its own WebGL2 shaders.
- **Design research:** `x design research <url>` measures a reference site in Chrome into a `defineTheme` proposal and a motion map; `x shot --against` measures how close a route came.
- **An agent kit every app keeps current:** `x new` writes five skills and five agents, `x kit` refreshes them, and `x verify` reports drift (`X_KIT_DRIFT`).

### Added

- `@ultimat3/ui/motion`: `motionTiming`, `animate`, `stagger`, `inView`, `scrollLinked`, `layout` (FLIP), `Presence`, `PresenceList`, `frameLoop`, `motionAllowed` / `onMotionChange` and `springLinear`, with spring rungs `gentle`, `snappy` and `bouncy` (`t.easing(snappy)`; `defineTheme({ motion: { easing: { snappy } } })` overrides one). One WAAPI engine on the token scale, no dependency; a barrel-only island carries zero motion bytes (pinned). See [Motion](https://github.com/developerz-ai/ultimate/wiki/Motion).
- `@ultimat3/ui`: `MotionToggle`, the WCAG 2.2.2 page-wide pause (`html[data-motion="paused"]`, keys `ui.motion.pause` / `ui.motion.resume` in en, ro, es and pt-BR); `@mixin view-transition-name($name)`; `@mixin shimmer` (`Skeleton` uses it, unchanged); `renderComponentsCatalog` and `bun run catalog <root> <glob> <title>` for another package's CATALOG.md.
- `@ultimat3/effects` (new, tier 5, 0 B for an app that does not import it):
  - Backgrounds: `Aurora`, `GradientOrbs`, `MosaicGrid`, `GridGlow`, `Noise`, `ShaderBackground` (`mesh` / `grain` / `dots`, each preset its own lazy chunk).
  - Interaction and text: `SpotlightCard`, `Tilt`, `GlassSurface`, `Marquee`, `TextReveal`, `CountUp`, `Shimmer`, plus `EffectCanvas`.
  - How every entry behaves: the server renders frame 0, colours come from role tokens, the effect pauses offscreen, in a hidden tab, under reduced motion and on `MotionToggle`, `data-effect-backend` says `static`/`css`/`canvas`/`webgl2`, and no entry makes a network request (sealed by test).
  - The WebGL2 mount and the GLSL are written from scratch.
  - Errors and docs: `X_EFFECTS_INVALID_VALUE`. See [Effects](https://github.com/developerz-ai/ultimate/wiki/Effects).
- `x design research <url…> [--follow n] [--viewport] [--allow-hosts] [--timeout] [--json]` and `--list`:
  - What it does: measures a public reference page in Chrome over raw CDP. Per URL it writes shots at 390/1440 × light/dark, `reference.json`, a contrast-checked `tokens.proposal.json` that `defineTheme` accepts, `motion-map.json` and `sources.json` with the licence posture.
  - Address screening: every navigation, redirect and subresource is screened browser-wide against private, loopback and link-local addresses (`X_DESIGN_URL_REFUSED`). A failed navigation is `X_DESIGN_REFERENCE_UNREACHABLE`.
  - `x shot <route> --against <ref>` writes a diff and a similarity score into `verdict.json`, recorded but never gating; a missing pair is `X_SHOT_AGAINST_MISSING`.
  - Hardening: cancellable (`X_ABORTED`), each reference published as a whole directory, a failed `--follow` link recorded in `skipped` without failing the run, page-chosen URLs reported as `origin#hash`, and WebSockets refused inside a reference.
  - The dev MCP gains `ui.research` (24 tools).
  - See [Design research](https://github.com/developerz-ai/ultimate/wiki/Design-Research).
- The agent kit:
  - What `x new` writes: five skills (`feature`, `planx`, `verify`, `upgrade`, `design-research`), five agents (`shape`, `data`, `server`, `web`, and a read-only `audit`), `.claude/kit.json`, and an app-owned `apps/web/DESIGN.md`.
  - `x kit` refreshes the managed files and never touches `app-*` or `"off"` entries.
  - `x verify`'s `manifest` step judges the kit: `X_KIT_DRIFT`, and `X_KIT_SHADOWED` for an app file under a managed name. With no marker it is one warning.
  - `x doctor` reports the kit, and `x upgrade` runs `x kit` after the guards.
  - See [Agents](https://github.com/developerz-ai/ultimate/wiki/Agents).
- Guards, report-only in an existing app and gating in a new one: `motion-adapter`, `raw-frame-loop`, `effect-without-fallback`, `raw-motion-script` and `animated-layout-script`. They refuse a third-party animation or GL engine, a bare `requestAnimationFrame`, a canvas outside `EffectCanvas`, and literal timings or layout keys in `.animate()`.
- `x new --shape dashboard` uses `Presence`, `stagger`, `inView`, `layout` and view-transition names. Every shape's landing sits on a CSS-tier `Aurora` (0 kB). `x g island <name> --effect <entry>` wraps the island in an effect.
- `x shot`'s verdict `gpu` gains `webgl2`.
- `MOTION_STORAGE_KEY` (`@ultimat3/core`, `@ultimat3/core/page`): the inlined theme boot stamps `html[data-motion="paused"]` from it before first paint on every page, so a reader's pause holds before any island hydrates.

### Changed

- `x new` no longer writes `.claude/commands/`. The skills replace them, and `x upgrade` (codemod `agent-kit`) deletes an unedited old command or agent and renames an edited one to `app-<name>.md`. Codemods `settings-kit-allow` and `docs-visual-quality` carry the allowlist entries and the AGENTS.md rows.
- The scaffold's `x.verify.json` sets `agentsMdMaxBytes: 13120`, a measured +1,120 B for the new guard rows and the Visual quality section. An existing app keeps its own budget.
- `x new --shape dashboard`'s `/dashboard` budget is 78kb, up from 60kb: it measured 76,839 B with the motion island.
- `render`: a navigation takes no view transition when the reader has paused motion, the same as under reduced motion.
