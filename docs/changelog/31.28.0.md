## 31.28.0 - 2026-11-15

### Highlights

- `x upgrade` carries an app's scaffold files forward with **codemods**: every scaffold-owned change between your version and the target is applied, and a file you edited is listed with its diff and never overwritten. Apps scaffolded at 31.4, 31.15, 31.20 and 31.22 reach 31.28.0 with no hand edit (`scripts/upgrade-fixtures.ts`, run in CI).
- Shipped guards run **built in** from the installed framework: an app's `guards/` holds only its own guards plus `guards/shipped.json` (a severity per shipped guard). `x upgrade` removes the old copies; one left behind is an `X_GUARD_VENDORED` warning with its diff.
- A stopped `x upgrade` can be finished by running it again to the same `--to`; a second `x upgrade` in one app is refused while one runs (`X_UPGRADE_LOCKED`), and Ctrl-C stops the hop's own children.
- `x repro --bundle` writes a redacted, self-contained bug bundle (values stood in by default, credentials scrubbed in every encoding); `create-ultimate repro <bundle.json>` opens it as a scratch app whose test is rebuilt from the bundle's subject, never run from its text.
- `solid-js` 1.9.18 everywhere (closes the seroval advisories); `x doctor` reports a resolved dependency below its advisory floor (`X_ADVISORY_FLOOR_UNMET`).

### Added

- `@ultimat3/cli`: `x upgrade codemods --from <version>`; `data.codemods` (`applied`, `skipped`, `reinstalled`, `failure`) on every hop; the `runtime-pin` shipped guard (every Bun pin site agrees) and its codemod; `guards/shipped.json`; `x repro --bundle` / `--include-rows`; `x doctor` reports superseded workarounds, advisory floors and codemods an older CLI's hop left owed. Codes: `X_GUARD_VENDORED`, `X_GUARD_BUILT_IN`, `X_SUPERSEDED_WORKAROUND`, `X_ADVISORY_FLOOR_UNMET`, `X_UPGRADE_CODEMODS_PENDING`, `X_UPGRADE_LOCKED`, `X_REPRO_BUNDLE_INVALID`.
- `create-ultimate repro <bundle.json>`.
- `@ultimat3/core`: the `storage.multipart` instrument event; `withStoreMode` refuses an overlapping, non-nested declaration.
- `@ultimat3/testing`: `x exercise` records storage writes (`put`, `copy`, `delete`, multipart session changes) as a call's effects.

### Changed

- `x new` writes 191 files (was 240): no shipped guard is copied into `guards/`. An app's `x.manifest.json` lists every built-in guard's code, owned by `@ultimat3/cli`.
- The scaffold's format hook runs the app's installed Biome or nothing (it no longer `bunx`-downloads), and every printed lint command says `bunx @biomejs/biome`.
- A template change with no codemod or written reason fails the repository gate (`X_TEMPLATE_CODEMOD_MISSING`).

### Security

- Credential key names redact more spellings (`SMTP_PASS`, `DB_PWD`, `*_KEY` key material, `Proxy-Authorization`, session ids, TOTP seeds, webhook URLs, `code_verifier`, `SAMLResponse`); `password` matches anywhere in a key again, with named readable exceptions (`hasPassword`, `passwordMinLength`).
- Error rendering escapes C1 control characters (`\u009b` is a one-byte terminal CSI) in core and in `@ultimat3/schema`'s copy.
- Codemod writes refuse a symlink that resolves outside the app root.
