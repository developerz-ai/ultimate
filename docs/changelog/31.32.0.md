## 31.32.0 - 2026-11-16

### Highlights

- **The security and robustness ratchets are burned down** (plan 101b slice 12 M6). Every site eight guards pinned across `cli`, `scripts` and every package was repaired, or keeps one row with a permanent written reason. Done by the guards' own repair, never a dodge:
  - secret compares are timing-safe;
  - computed reads of lookup tables are prototype-guarded;
  - every value a `fix:` line pastes is shell-screened;
  - every fetch carries a signal, every child process a timeout, every numeric option a finite screen;
  - every `info` line states why it is news.
- **Real bugs the burn-down found:**
  - a `fix:` line that ran a reader's own `$(…)` when pasted (`x db branch …`);
  - lookups that answered the `Object` function for a key named `constructor` (`poolProfileFor`, the admin field map, `tierOf`, `x doctor`'s duplicate-package cause);
  - fix lines a shell read as pipes;
  - a hung coverage unit nothing killed.

### Fixed

- `x` fix lines quote every value they paste, so a reader's own word such as `$(id)` can no longer run when the line is pasted (`x db branch …`). Every framework package's fix lines screen what they paste (`renderFixShellArg`).
- `@ultimat3/db` `poolProfileFor()` refuses a non-role with `X_ROLE_INVALID` (`'constructor'` used to answer the `Object` function as a pool profile).
- `@ultimat3/admin`: a column kind named after an `Object.prototype` member is refused with `X_ADMIN_FIELD_UNSUPPORTED`; `ruleFor` refuses an unknown operation.
- `@ultimat3/mail` `token()` refuses an unknown name. `@ultimat3/pwa` `strategyFor` answers `network-only` for an unknown mode. `@ultimat3/render` `surfaceAllows` answers `false` for an unknown surface; it used to throw a bare `TypeError`.
- `@ultimat3/testing` `runJobs` traces count a step named `constructor` or `__proto__`.
- `@ultimat3/admin` / `@ultimat3/ui`: a non-finite logo `width` or Textarea `rows` raises `X_INVARIANT` instead of rendering `NaN`.
- `@ultimat3/entity`: the `X_N_PLUS_ONE_WRITE` fix no longer pastes the `Object` function's source. `x doctor`'s duplicate-package cause no longer prints a function for a package named like a prototype member.
- `@ultimat3/core`:
  - the `X_ENVIRONMENT_INVALID` fix is a runnable `export ULTIMATE_ENV=production` (it used to be a line a shell ran as pipes);
  - the dev-secret checks, in `core`, `storage` and `action`'s idempotency fingerprint, compare in constant time.
- `@ultimat3/db`: the `unknown-schema` drift fix degrades to `git status` for a migration id a shell would reinterpret, never a glob over every snapshot.
- `x shot --cdp-url`: its discovery request is bounded by the session timeout (`X_CDP_CALL_FAILED`).
- Scripts:
  - `checkTier('toString')` no longer crashes;
  - `new-package --only` no longer prints a pipeline as its fix;
  - coverage-gate kills a hung unit (`X_SPAWN_TIMED_OUT`);
  - a crashed render bench probe is `X_BENCH_RUN_FAILED`, never a 0 MiB reading.
- `compat.yml` and the nightly flake-hunt name the tests that failed. CI prints each file inside a `::group::` marker, and both reported "0 failing tests".
- `@ultimat3/time`'s formatter-cache test counts `Intl.DateTimeFormat` constructions over 4,096 casings (0), not the process heap, which flaked when it shared a worker with other suites.
- The `runtime-bus` live test waits for the reconnect line, which since 31.30.0 is said after the server holds the subscriptions.

### Changed

- `x db gen` drift fixes single-quote the migration description.
- `quoteArg` (`@ultimat3/cli`) takes a word list too, quoting each word.
- The `roadmap` step refuses a plan tracker changed on the branch whose `last_updated` did not move (`X_PLAN_STATUS_UNDATED`); a depth-1 CI clone dates trackers by that line.
- `scripts` coverage pin 83/89 → 84/90.
